# Task 13 — Чотири помилки в моделі даних Git

Відповідь:

1) Спіральні посилання на батьків (цикли) — Git ґарантує спрямований ациклічний граф комітів, тому цикли у моделі вказують на помилку моделювання.  
2) Неврахування відліку часу та метаданих — модель комітів без авторів/часу ускладнює відстеження історії і вирішення конфліктів.  
3) Ігнорування відгалужень як окремих послідовностей — зведення гілок до простого списку втрачає інформацію про паралельну роботу та злиття.  
4) Заміна SHA-ідентифікаторів на неунікальні ключі — унікальність ідентифікаторів є критичною; її втрата призводить до плутанини і колізій при злиттях.
