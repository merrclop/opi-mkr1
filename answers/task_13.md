# Завдання 13. Знайдіть помилки в поясненні моделі даних Git (середнє)

У поясненні моделі даних Git є чотири помилки: знайдіть їх, виправте й поясніть наслідок.

**Тема.** Лекція 3, розділ 3.2 (модель даних: знімки й об'єкти).

**Умова.**

Нижче наведено пояснення, яке дав новачок у команді.

> У Git кожен коміт зберігає лише список змін відносно попереднього коміту, тому щоб отримати стару версію проєкту, Git послідовно застосовує всі зміни від першого коміту. Ідентифікатор коміту — це випадковий номер, який Git видає під час створення коміту. Якщо файл не змінився між двома комітами, у сховищі лежать дві його копії, по одній на кожен коміт. Команда `git commit --amend`, яка змінює лише текст повідомлення останнього коміту, не змінює його ідентифікатора, бо файли ті самі.

У цьому поясненні чотири неправильні твердження. Для кожного: вкажіть, що саме неправильно, і поясніть, як це влаштовано насправді. Окремо поясніть, чому з правильної відповіді на четверте твердження випливає, що переписувати вже опубліковані коміти небезпечно для колег.

**Формат відповіді.** Короткий структурований текст (за пунктами або абзацами), кожне твердження з поясненням. Орієнтовний час 12–15 хв. Запишіть відповідь у файл `answers/task_13.md` після рядка «Відповідь:».
